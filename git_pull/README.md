# Muthur Command App: Git pull

Load and update configuration files for Muthur Command from a Git repository.

![Supports aarch64 Architecture][aarch64-shield] ![Supports amd64 Architecture][amd64-shield]

You can use this app (formerly known as add-on) to `git pull` updates to your Muthur Command configuration files from a Git
repository.
