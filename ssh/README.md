# Muthur Command App: SSH server

Allow logging in remotely to Muthur Command using SSH or just the web terminal with Ingress.

![Supports aarch64 Architecture][aarch64-shield] ![Supports amd64 Architecture][amd64-shield]

## About

Setting up an SSH server allows access to your Muthur Command folders with any SSH
client. It also includes a command-line tool to access the Muthur Command API.
